🎯 Overview
A simple Python implementation of the classic Bulls & Cows game.
The computer generates a 3‑digit random number with unique digits, and the player gets 8 chances to guess it.

🎮 Game Rules
The computer picks a 3‑digit number (100–999) with no repeated digits.

After each guess, the game reports:

Bulls → Correct digit in the correct position

Cows → Correct digit but wrong position

Win by getting 3 bulls within 8 attempts.

▶️ Running the Game

python Play_Game.py

📌 Features
Unique‑digit random number generation

Bulls & Cows calculation using dictionary comparison

Input‑driven interactive gameplay

Clear attempt tracking (8 chances)
