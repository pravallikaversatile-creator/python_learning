⭐ Access Modifiers in Python
Python supports three levels of access:

Public

Protected

Private

These are implemented using naming conventions, not strict rules.

⭐ Summary Table (Perfect for Notes)

Modifier	Syntax	Access Level	Enforced?	Use Case
______________________________________________________________________________
Public		var	Everywhere	    No		Normal attributes

Protected	_var	Class + Subclass    No		Internal use

Private 	__var	Class only
			(name‑mangled)    Partially	Sensitive data
