x=a+b --- This is an expression. "+" and "=" are operators, x,a and b are operands. Operator is "+" and operation is assignment(=) operation

x>>y is equal to x/(2^y)
x<<y is equal to x*(2^y)

1) Arithmetic operators
● +, -, *, /, %, **, //
2) Assignment operators

● =, +=, -=, *=, /=, and so on

3) Comparison operators
● >, <, >=, <=, ==, !=

4) Logical operators
● and, or, not
5) Identity operators
● is, is not
6) Membership operators
● in, not in
7) Bitwise operators
● &, |, ^, ~, >>, <<

/ → normal division

7 / 2    # 3.5

// → floor division (round down)

7 // 2   # 3
-7 // 2  # -4

math.ceil(x) → round up

import math
math.ceil(3.5)   # 4
math.ceil(-3.5)  # -3

Floor → go down ⬇️
Ceil → go up ⬆️
