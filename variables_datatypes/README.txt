Programs does data manipulation through input and output. 
This data need to be temporarily stored.
The containers used for this purpose of data storage are called variables.

variables rules: can start Upper and Lowercase letters, _
Should not start with number, but can contain alphanumerics and _ in between
Python is case sensitive.

Data types: The process of assigning various kinds of types to various data are called Data types. These are storages for variables.

Types: 
Numeric : Integer(+ve, -ve and 0), Float(decimal point numbers), Complex(combination of Real and imaginary numbers 3+4j) 
Boolean : 1 or 0.(3>4)
Sequence : strings, list, tuple
Dictionary 
Set
