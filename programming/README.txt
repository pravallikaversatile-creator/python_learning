The processor (CPU) is the component that executes instructions and controls the operation of the computer.
Programming/coding: Its a process of communicating with the processor.
Programming Language: A medium to communicate to the processor. 
Coders/programmers: People who communicate with processors using a programming language
Program/code: Instructions/commands.
Software: A collection of codes/programms to accomplish a task
The processor will be runing the above software.
Processors are made of logic gates. Processor understands only voltage levels, 5v High and 0v lowFor the processor to understand the coding language(which is a high level language), the compiler compiles the program and converts(encodes) the HLL to an assembly level language,(understandable by the computer) which is 5v for  and 0v for logic 0.
To store the data in processor, there are registers, main memory, secondary memory and cache memory.
The program we write is stored in secondary memory. 
But the processor will be able to run the program from the data stored in register memory. 
The reason program data is fetched from secondary memory to Register memory is because of memory hierarchy.
Speed: 1KB Register file >>>> 1MB Cache Memory >>> 1GB Main Memory >> 1TB Secondary memory.
Cost: 1KB Register file >>>> 1MB Cache Memory >>> 1GB Main Memory >> 1TB Secondary memory.
